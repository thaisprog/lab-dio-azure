# lab-dio-azure
A criação de uma instância de banco de dados no Azure é basicamente o momento em que a nuvem transforma infraestrutura pesada em um serviço pronto para uso.

Em vez de comprar servidores, montar hardware e instalar sistemas manualmente, o Azure faz todo o trabalho pesado nos bastidores em instantes:

Alocação automática: Transforma recursos físicos (CPU, memória e disco) em capacidade lógica pronta para uso.

Tudo pronto num clique: Redes seguras, discos criptografados e o próprio motor do banco de dados são configurados em minutos via automação.

Segurança e resiliência ativas: O recurso nasce com criptografia, regras de firewall e cópias de segurança (réplicas) preparadas para evitar quedas.

Na prática, a criação é a virada de chave onde você deixa de gastar tempo cuidando da máquina para focar apenas nos dados e na sua aplicação.
